# hello_weixin_book — 网文/书籍分析

我吃西红柿等网文与《孙子兵法》等书籍的深度分析 HTML 产出，供阅读、选题与内容二次创作。

## 目录地图

```
hello_weixin_book/
├── README.md
├── INDEX.md                 # 分析稿清单（按作品）
├── analyses/                # *分析.html / *时间线.html / *蒸馏.html / 总览
└── assets/
    ├── generated-images/    # 生成图
    └── outputs/             # 海报等产出
```

## 使用方式

- 浏览器直接打开 `analyses/*.html`
- 清单与主题分类见 [INDEX.md](INDEX.md)
- 与小说业务的关系：书评分析可服务 `hello_novel` 选题与公众号选题，**不包含**原著章节正文
