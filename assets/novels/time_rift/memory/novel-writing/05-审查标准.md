# 连贯性审查标准

---

## 审查频率

| 频率 | 检查内容 |
|------|----------|
| 每章完成后 | 长度、一致性、新角色/伏笔追踪 |
| 每卷完成后 | 全面连贯性审查、角色出场更新、伏笔追踪更新 |
| 全书完成后 | 全系列审查、所有伏笔回收确认、主题首尾呼应 |

---

## 审查维度清单

---

### 一、剧情过渡检查

#### 1.1 章节间过渡

| 检查项 | 标准 | 问题示例 |
|--------|------|----------|
| 场景切换 | 有明确的时间/地点标注 | 上一章在A地，下一章突然在B地无交代 |
| 情绪衔接 | 相邻章节情绪变化有铺垫 | 上一章激烈战斗，下一章突然轻松日常 |
| 信息承接 | 前章揭示的信息在后章有回应 | 上一章发现线索，下一章完全不提 |
| 角色状态 | 角色的伤势/情绪/位置保持连续 | 上一章受伤，下一章毫无影响 |

**过渡质量评分**：
- ✅ 优秀：过渡自然，读者无感知
- ⚠️ 合格：过渡生硬但可接受
- 🔴 失败：过渡断裂，读者困惑

#### 1.2 场景切换规范

```markdown
# 好的场景切换

## 方式一：时间标注
> **时间**：三天后，新上海市政府大楼

## 方式二：分隔线+环境描写
---

新上海的黎明来得比以往更早。
（通过环境描写暗示时间变化）

## 方式三：角色对话过渡
"三天了，我们该出发了。"李明说。
（通过对话自然引出时间跳跃）
```

```markdown
# 坏的场景切换

## 问题一：无标注跳跃
（上一章在底层战斗）
（下一章直接在办公室开始，无任何过渡）

## 问题二：情绪断裂
（上一章角色悲痛欲绝）
（下一章角色开怀大笑，无过渡）
```

#### 1.3 时间跳跃处理

| 跳跃长度 | 处理方式 | 示例 |
|----------|----------|------|
| 数小时 | 简单标注即可 | "三小时后" |
| 1-3天 | 一句话过渡 | "三天后，伤势痊愈" |
| 1周-1月 | 需要交代变化 | "一个月后，城市已经重建" |
| 数月-数年 | 需要详细过渡 | 独立过渡章节，交代变化 |

### 二、剧情连贯性检查

#### 2.1 因果链检查

每个重要事件必须有清晰的因果链：

```
原因 → 事件 → 结果 → 影响
```

**检查清单**：
- [ ] 重要事件的发生有充分铺垫
- [ ] 事件的结果在后续章节中有体现
- [ ] 角色的决策有合理的动机
- [ ] 剧情转折有逻辑支撑

**常见因果链断裂**：
| 问题 | 示例 | 修复方式 |
|------|------|----------|
| 无因之果 | 角色突然获得新能力 | 增加铺垫章节 |
| 有因无果 | 发现重要线索后不再提及 | 补充结果章节 |
| 因果倒置 | 先有结果再补原因 | 调整章节顺序 |
| 因果矛盾 | 同一原因导致不同结果 | 统一逻辑 |

#### 2.2 信息流检查

信息在故事中的流动必须合理：

```
信息源 → 传递 → 接收 → 理解 → 行动
```

**检查清单**：
- [ ] 角色获取信息的渠道合理
- [ ] 信息传递没有遗漏（A告诉B，B必须在后续体现）
- [ ] 角色对信息的反应符合性格
- [ ] 信息的保密/公开有合理逻辑

**信息流断裂示例**：
| 问题 | 示例 | 影响 |
|------|------|------|
| 信息丢失 | A告诉B重要信息，B后续完全忘记 | 角色不一致 |
| 信息超载 | 角色突然知道不该知道的事 | 逻辑漏洞 |
| 信息延迟 | 重要信息很久才被使用 | 节奏拖沓 |
| 信息矛盾 | 同一信息在不同章节有不同版本 | 设定混乱 |

#### 2.3 角色行为一致性

角色的行为必须符合其性格和处境：

**检查清单**：
- [ ] 角色的决策符合其性格设定
- [ ] 角色的能力水平前后一致
- [ ] 角色的情感反应合理
- [ ] 角色的关系变化有铺垫

**行为不一致示例**：
| 问题 | 示例 | 修复方式 |
|------|------|----------|
| 性格突变 | 谨慎角色突然鲁莽行动 | 增加心理铺垫 |
| 能力膨胀 | 角色突然变得无所不能 | 增加限制和代价 |
| 情感失真 | 角色对重大事件反应冷淡 | 增加情感描写 |
| 关系跳跃 | 关系发展过快无过渡 | 增加互动场景 |

#### 2.4 世界观一致性

世界观的规则必须前后统一：

**检查清单**：
- [ ] 科技设定前后一致
- [ ] 社会规则前后一致
- [ ] 超自然/科幻规则统一
- [ ] 地理/空间描述一致

**世界观矛盾示例**：
| 问题 | 示例 | 影响 |
|------|------|------|
| 科技矛盾 | 前文说不可能，后文轻松实现 | 逻辑漏洞 |
| 规则矛盾 | 超能力规则前后不一 | 设定混乱 |
| 空间矛盾 | 地理位置描述不一致 | 读者困惑 |
| 社会矛盾 | 社会规则前后不同 | 世界观崩塌 |

### 三、节奏连贯性检查

#### 3.1 张力曲线检查

```
张力
 │    ╱╲      ╱╲      ╱╲
 │   ╱  ╲    ╱  ╲    ╱  ╲
 │  ╱    ╲  ╱    ╲  ╱    ╲
 │ ╱      ╲╱      ╲╱      ╲
 └────────────────────────────→ 章节
   高潮  喘息  高潮  喘息  高潮
```

**检查清单**：
- [ ] 高潮和喘息交替出现
- [ ] 连续高潮不超过3章
- [ ] 连续喘息不超过5章
- [ ] 张力整体呈上升趋势

**节奏问题示例**：
| 问题 | 表现 | 修复方式 |
|------|------|----------|
| 高潮疲劳 | 连续多章高强度 | 插入喘息章节 |
| 节奏拖沓 | 长时间低张力 | 增加小冲突 |
| 高潮突兀 | 无铺垫突然高潮 | 增加铺垫章节 |
| 喘息不足 | 高潮后立即新冲突 | 增加过渡 |

#### 3.2 信息密度检查

每章的信息量需要控制：

**检查清单**：
- [ ] 单章新信息不超过3个
- [ ] 重要信息有足够展开空间
- [ ] 信息揭示有层次（先暗示后明确）
- [ ] 复杂概念有解释

**信息密度问题**：
| 问题 | 表现 | 修复方式 |
|------|------|----------|
| 信息过载 | 一章揭示太多新概念 | 拆分到多章 |
| 信息稀薄 | 大量篇幅无新信息 | 增加内容或精简 |
| 信息突兀 | 重要信息无铺垫突然出现 | 增加暗示 |
| 解释不足 | 复杂概念未解释 | 增加说明段落 |

### 四、伏笔连贯性检查

#### 4.1 伏笔生命周期

```
埋设 → 发酵 → 强化 → 揭示 → 回收
```

**检查清单**：
- [ ] 每个伏笔都有追踪记录
- [ ] 伏笔在等待期间有定期强化
- [ ] 伏笔揭示时机合理
- [ ] 伏笔回收后有情感回应

#### 4.2 伏笔健康度评估

| 指标 | 健康 | 亚健康 | 危险 |
|------|------|--------|------|
| 等待章数 | <50章 | 50-100章 | >100章 |
| 强化频率 | 每20章一次 | 每50章一次 | 从未强化 |
| 揭示铺垫 | 3章以上铺垫 | 1-2章铺垫 | 无铺垫直接揭示 |
| 回收完整度 | 完全回收 | 部分回收 | 未回收 |

#### 4.3 伏笔断线预警

| 预警级别 | 条件 | 处理方式 |
|----------|------|----------|
| 🟢 正常 | 等待<30章，有强化 | 继续观察 |
| 🟡 预警 | 等待30-50章，无强化 | 立即安排强化 |
| 🔴 危险 | 等待>50章，无强化 | 必须在本卷回收或强化 |
| ⚫ 断线 | 等待>100章 | 伏笔已失效，需补救 |

---

### 五、角色连贯性检查

#### 5.1 角色出场追踪

| 指标 | 正常 | 预警 | 危险 |
|------|------|------|------|
| 主角 | 每章出场 | — | — |
| 重要配角 | 每10-20章 | 每30章 | >50章 |
| 普通配角 | 每30-50章 | 每80章 | >100章 |
| 反派 | 每20-30章 | 每50章 | >80章 |

#### 5.2 角色弧线检查

**检查清单**：
- [ ] 每个重要角色有明确的弧线起点和终点
- [ ] 角色成长有足够的情节支撑
- [ ] 角色转变有合理的动机和过程
- [ ] 角色结局与弧线起点形成呼应

**弧线问题示例**：
| 问题 | 表现 | 修复方式 |
|------|------|----------|
| 弧线断裂 | 角色发展中途停滞 | 增加发展章节 |
| 弧线突变 | 角色转变过快无铺垫 | 增加过渡 |
| 弧线缺失 | 角色引入后无发展 | 补充发展线 |
| 弧线矛盾 | 角色发展方向前后不一 | 统一发展方向 |

---

### 六、卷间过渡检查

#### 6.1 卷间衔接要素

| 要素 | 检查内容 | 示例问题 |
|------|----------|----------|
| 时间 | 卷间时间跨度是否合理 | 上一卷结束是战斗，下一卷开始是和平，无过渡 |
| 空间 | 地点变化是否有交代 | 上一卷在城市，下一卷在太空，无说明 |
| 角色 | 角色状态是否连续 | 上一卷受伤，下一卷完好，无解释 |
| 剧情 | 主线是否延续 | 上一卷的危机在下一卷完全消失 |
| 伏笔 | 跨卷伏笔是否强化 | 上一卷埋的伏笔在下一卷被遗忘 |

#### 6.2 卷间过渡质量评分

| 评分 | 标准 |
|------|------|
| ★★★★★ | 卷间过渡自然流畅，读者无感知断裂 |
| ★★★★☆ | 卷间有小跳跃但有合理交代 |
| ★★★☆☆ | 卷间过渡生硬但可接受 |
| ★★☆☆☆ | 卷间有明显断裂但不影响理解 |
| ★☆☆☆☆ | 卷间严重断裂，读者困惑 |

#### 6.3 跨卷伏笔追踪

```markdown
## 跨卷伏笔清单

| 伏笔 | 埋设卷 | 预计回收卷 | 当前状态 | 强化记录 |
|------|--------|------------|----------|----------|
| 伏笔A | 第一卷 | 第三卷 | 等待中 | 第二卷第50章强化 |
| 伏笔B | 第一卷 | 第二卷 | 已回收 | — |
| 伏笔C | 第一卷 | ? | 危险 | 从未强化 |
```

## 质量评分标准

| 维度 | 5分（优秀） | 3分（合格） | 1分（需改进） |
|------|-------------|-------------|---------------|
| 开篇吸引力 | 前5章抓住读者 | 前10章建立兴趣 | 前20章仍在铺垫 |
| 角色塑造 | 有辨识度、有成长 | 基本一致 | 前后矛盾 |
| 剧情连贯性 | 伏笔全部回收 | 主要伏笔回收 | 多条断线 |
| 情感深度 | 有让人落泪的场景 | 有情感起伏 | 情感平淡 |
| 世界观一致性 | 完全一致 | 主要一致 | 设定矛盾 |
| 结尾收束 | 主题首尾呼应 | 基本收束 | 虎头蛇尾 |

**目标**：每个维度至少3分，总分不低于24分（满分30分）

## 问题严重程度定义

| 程度 | 定义 | 处理方式 |
|------|------|----------|
| 🔴 严重 | 伏笔断线、角色消失、设定矛盾 | 立即修复 |
| 🟡 中等 | 节奏失衡、角色弱化、描写不足 | 下一卷修复 |
| 🟢 轻微 | 细节不一致、描写过长 | 有空时修复 |

---

## 修复优先级指南

发现多个问题时，按以下顺序修复：

### 第一优先：逻辑类问题
1. 因果链断裂（如"有因无果"）
2. 世界观矛盾（如科技设定不一致）
3. 角色行为矛盾（如谨慎角色突然鲁莽）

### 第二优先：结构类问题
4. 伏笔断线（超过50章未强化）
5. 角色消失（超过出场阈值）
6. 卷间衔接断裂

### 第三优先：体验类问题
7. 节奏失衡（高潮/喘息比例不当）
8. 信息密度异常（过载或稀薄）
9. 过渡生硬（场景切换突兀）

### 第四优先：品质类问题
10. 剧情关联不足（建议增加呼应或伏笔）
11. 情感深度不足（建议增加情感场景）
12. 主题表达不足（建议增加首尾呼应）
