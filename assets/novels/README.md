# assets/novels — 创作资产（小说书目 + 主题文集）

> 本 README 为原 family-life-video 内容线说明（2026-10 迁入）。书目文件夹见同级目录。

一句话定位：家庭亲情题材情感短视频的**内容稿资产线**——人物特稿、口播脚本、分镜脚本；成片制作由 `assets/douyin`（豆包分镜成片）承担，本线为其上游选题与脚本供给。

## 目录地图

```
assets/novels/
├── README.md                      # 本文件
└── <主题>/                        # 一个主题一个目录（如 父亲的手/、母亲的灶台/）
    ├── 人物特稿/*.md              # 人物背景与情感基调（跨主题共享时放本层 人物特稿/）
    ├── 短视频脚本.md              # 口播稿
    └── 视频分镜脚本.md            # 分镜表（镜头/画面/台词/时长）
```

现有主题：`父亲的手`、`母亲的灶台`、`人物特稿/农村65后父亲的蹉跎岁月`。

## 与平台的关系

- 本线**纯内容、无代码、无配置**，不依赖 `core/`（与 `personal-read-book` 仓库 同类的内容资产线）。
- 分镜脚本的画面描述可直接作为 `assets/douyin` 的分镜提示词输入；成片流程见该线 README。
- 平台层 CLI/看板对稿件目录不做扫描；需要入库检索时走 `media-cli.py asset scan`（当前仅支持 novel 类型，视频脚本类型为规划项）。

## 常用流程

1. 新主题：建 `<主题>/` 目录，先写 `短视频脚本.md`（口播），再拆 `视频分镜脚本.md`。
2. 成片：把分镜交给 `assets/douyin` 流程（提示词库见其 `docs/`）。
3. 登记新主题：更新本 README「现有主题」。
