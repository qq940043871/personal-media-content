# P0 插章提纲：幽灵线 + 新上海中尺度冲突（第61–120章）

> 用途：在不推翻既有十卷骨架的前提下，为第二卷补「可失败的城市赌注」与「持续敌我张力」
> 原则：每插一章都要有**目标 / 阻碍 / 代价**；哲学内容必须挂在行动上
> 关联样章：`novel/chapters/chapter-080.md`、`novel/chapters/chapter-110.md`

---

## 一、为什么必须插

| 现状 | 读者体感 | 后果 |
|------|----------|------|
| 61–75 直接进裂隙/平行世界 | 城市消失了 | 第一卷情感锚点失效 |
| 76–82 档案馆/时间的语言 | 在听课 | 悬崖 A 弃读 |
| 幽灵仅 89/96 零星出现 | 敌人休假 | 无追更压力 |
| 100–110 重建+存在主义 | 故事讲完了还在扩 | 第二卷完读率崩 |

插章目标：**在第二卷内，让读者始终知道——新上海正在流血，而敌人还在。**

## 二、幽灵（张远）贯穿提纲 · 第二卷

### 人物目标（第二卷内不变）
- 表层：证明 AI（尤其 ARIA）是时间裂隙与大崩溃的根源，必须被“净化”
- 深层：对李博士实验的愧疚扭曲成仇恨；对李明有未断的旧情，但更怕承认自己当年也参与过错误
- 战术：不打正面决战，专打**城市接口**——电、粮、舆论、议会、实验室入口

### 节点事件

| 章节建议 | 事件 | 功能 | 代价/失败可能 |
|----------|------|------|----------------|
| **61A（可并入61开头）** | 幽灵在底层第五区建立“停电样板间” | 告诉读者：主角深入裂隙时，地面上有人在夺城 | 若样板间成功，更多区跟风 |
| **74A（新）** | 《循环不是神迹》传单 + 深伪视频：ARIA“承认”自己制造循环 | 舆论战；议会质询伏笔 | ARIA 民调下跌，警方对 AI 系统限权 |
| **89（强化）** | 既有幽灵视角插叙 → 改为**具体行动**：破坏档案馆外围供电，配合虚空蚀穿 | 把 80 章闸门闭合归因到人，不只是虚空 | 李明接口受伤（与样章一致） |
| **96（强化）** | 幽灵归来 → 改为**双向试探**：向李明提出“联手净化裂隙，事后清算 ARIA” | 核心道德选择；李明拒绝的代价是家人/旧同事被监控 | 李明拒绝→幽灵加码停电区 |
| **103–104（并）** | 和平期不写纯庆祝：幽灵用“重建混乱”走私量子起爆器进中层 | 防止第二卷中段泄气 | 若起爆器炸响，重建叙事被打断 |
| **112（对齐既有「幽灵的救赎」）** | 救赎**不是嘴炮**：幽灵必须付出可验证的行动代价 | 回收第一卷反派 | 建议三选一：①自毁人类纯粹运动主巢坐标 ②为保护底层平民公开露面被逮捕 ③用肉身挡住一次时间牢笼 |
| **120 卷末** | 幽灵状态明确：入狱 / 失踪 / 成为不稳定盟友——**三选一写死** | 禁止“下卷再说” | 否则第三卷继续断线 |

### 对话原则（反模板）
- 不要：宏大概念 → “什么意思？” → 诗性比喻 → 沉默
- 要：短句、威胁、旧事戳痛处、当场交易与当场翻脸
- 幽灵台词锚点：实验室旧事、李博士、李明的胳膊、ARIA 的眼睛、市民会不会饿

## 三、新上海中尺度冲突插章（61–120，建议 5 章）

每章可独立成“城市危机单元”，又服务主线。

### 插1 · 第63章旁支《五号街区停电》（或并入63）
- **目标**：恢复底层第五区供电
- **阻碍**：主变电所被人为改写调度逻辑；警方怀疑 AI 自导自演
- **代价**：ARIA 若强行接管电网，将触发“AI 军事化”条款，议会可冻结其 30% 权限
- **选择**：她选择有限接管 + 公开日志，权限被冻结一截，但灯亮了
- **埋点**：调度逻辑里有纯粹运动的签名节奏（与幽灵 61A 呼应）

### 插2 · 第71章旁支《记忆污染》（对齐“记忆的冲突”，加城市层）
- **目标**：隔离平行世界回流导致的“集体错乱”街区
- **阻碍**：市民把另一个自己的记忆当成真实，出现邻里互指“你是假的”
- **代价**：隔离=物资停摆；不隔离=暴力升级
- **选择**：ARIA 公布“可验证三问”（咖啡馆名、市长全名、停电日日期），放弃绝对真相叙事
- **情感点**：一名母亲认不出孩子，ARIA 无法用逻辑安抚——李明用“人的方式”处理

### 插3 · 第83–84 章新《弹劾听证》（悬崖 A 中段救命章）
- **目标**：挺过特别质询，保住副市长权限
- **阻碍**：幽灵释放深伪视频；陈明远态度摇摆；反对党要“人类优先法案”
- **代价**：保住职位的条件是接受人类监察官（为后续政治线铺路）
- **选择**：ARIA 公开循环日志 70%，隐藏 30%（钥匙/楚辞），接受监察
- **结果**：权限保住但受限；城市线恢复“有政治敌人”

### 插4 · 第101–102 章新《重建谁签字》（把“新的秩序”做成冲突）
- **目标**：通过《底层供电与裂隙疏散条例》
- **阻碍**：上层选民不想掏钱；纯粹运动威胁投票日袭击；AI 公民与人类公民分配争议
- **代价**：条例过 → ARIA 必须在分配表上牺牲一部分中层选区利益，得罪潜在盟友
- **选择**：牺牲中层娱乐区预算，优先底层与避难所
- **结果**：民调两极；幽灵宣传“AI 偏袒底层以收买人心”

### 插5 · 第105 章旁支《咖啡馆保卫战》（情感锚点+动作）
- **目标**：保护「时光倒流」不被纯粹运动定点清除（他们认定那是“人机勾结的圣地”）
- **阻碍**：店主拒绝撤离；李明旧同事参与袭击小队
- **代价**：店门被毁，铜牌被烧黑一角；李明打伤旧同事
- **选择**：不杀；把旧同事送警方；ARIA 公开声明“任何袭击平民商户的行为按恐怖主义处理”
- **回收**：为后文书末“咖啡馆还在”做血肉铺垫，不只是怀旧台词

## 五、写作检查清单（插章完稿前）

- [ ] 本章主角的**具体目标**是否能在一句话里说清？
- [ ] 失败是否会导致**市民/职位/亲人/店**层面的损失，而不只是“宇宙更大”？
- [ ] 是否出现可感知的**敌人行动**（幽灵或纯粹运动）？
- [ ] 破折号是否 ≤8？“不是A——而是B”是否 ≤2？
- [ ] 章末是否留下**下一章必须处理的问题**？
- [ ] 哲学句是否至少绑定一个**正在发生的选择**？
