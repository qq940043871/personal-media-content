## 〇、结论摘要

**商业读者完读路径不是均匀下跌，而是“三次悬崖 + 一次回光”。**

| 悬崖 | 章节区间 | 弃读主因 | 严重度 |
|------|----------|----------|--------|
| 悬崖 A | 约第 76–120 章 | 从城市冒险滑向起源档案/存在主义对话；节奏从“解谜战斗”变成“听课” | 高 |
| 悬崖 B | 约第 121–240 章 | 舞台从城市扩到银河/维度/深渊；主角过强，威胁不可感 | 高 |
| 悬崖 C | 约第 301–480 章 | 创造空间/使命空间/概念生命 + 破折号模板化；中尺度冲突几乎消失 | 极高 |
| 回光 | 约第 481–540 章 | 叙事回到具体人事，第540章李明之死是全书情感峰值 | 中（能否到达存疑） |

**开篇（1–60章）是资产，不是问题。** 第一卷具象词占比 **0.68**（全书最高区间之一），第2章系统实验、第4章底层之影、第5章咖啡馆、第15章意识代价、第20章袭击，都是标准商业科幻节奏。**中后段是产品问题。**

**量化佐证（全书扫描，按卷）：**

| 卷 | 章节 | 均字数 | 均破折号 | 均抽象词频 | 均具象词频 | 具象占比 | 卷内破折号最重 |

| 五 | 241–300 | 7724 | 92.0 | 40.1 | 15.1 | 0.27 | ch246(253)/249(208) |

读法：

1. **具象占比**从第一卷 0.68 → 第三/七卷约 0.20，读者体感从“在新上海办案”变成“在概念里漂”。
2. **破折号**第二至五卷均破百/章，远超设定规范（每章 ≤5–8），直接制造“AI 作文感”。
3. **篇幅**从第一卷均 8700+ 掉到第九卷约 4900；不是“变精炼”那么简单，而是中后段长期欠具体冲突，后期靠短章收束。
4. 第九卷具象比回升到 0.67，说明**作者会写好故事**——问题是中段 300+ 章把大众读者耗光了。

## 二、逐卷续读断点诊断

### 第一卷（1–60）· 时间囚徒 —— 可投放

**体感**：强钩子、双线推进、有可感知代价。

| 章节 | 标题/功能 | 续读风险 | 诊断 |
|------|-----------|----------|------|
| 1–5 | 时间囚徒 / 无尽六月 / 咖啡馆 | 低 | 核心卖点成立：AI 市长被困同一天；第2章用实验推进，不是旁白灌设定 |
| 6–10 | 怀疑 / 幽灵注视 / 晨会秘密 / 机械之心 | **中** | 设定开始堆积；第10章林若突然出现（无铺垫），较真读者会不适 |
| 11–15 | 数据碎片 / 循环策略 / 合作 / 代价 | 低–中 | 第15章意识完整度下降是好“代价锚点”，建议全书持续引用 |
| 16–22 | 研究所 / 袭击 / 逃离 | 低 | 第20章“第一次袭击”具象、有敌我；商业节奏正确 |
| 23–30 | 过去 / 底层真相 / 陈明远 | 中 | 信息章偏多，但仍在城市悬疑框架内 |
| 31–45 | 裂隙扩大 / 牺牲 / 第一次胜利 | 低 | 本卷张力峰值区 |
| 46–60 | 时间之心 / 新威胁 / 新的开始 | 中 | 第60章末尾抛出“其他网络”，是好钩子；但**若下一卷立刻脱离城市**，转化会断 |

**第一卷弃读风险点（具体）**：

1. **第10章 林若/第八实验室**：角色一次性登场后长期消失（后续审查多次点名）。要么在 3–4 章埋线并贯穿，要么删除并入李博士档案。
2. **循环规则表述不一**：编号、重置时刻、“受害者 vs 锚点”前后不一。建议章首固定元数据：`循环 #N · 06:00 · 状态`。
3. **“楚辞”线索**：第3章埋设；后续报告对是否在第75章回收有分歧——**投放前必须通读确认**。若未充分回收，这是“读者记仇”型伏笔。
4. **破折号已在第一卷偏高**（均 62.6，ch10/59/60 过百），开篇文风已可再收紧。

**结论**：第一卷整体是全书最强资产。试读包做 **1–15章**，预期弃读点在 **第8–12章**（设定堆积 + 林若）。

### 第二卷（61–120）· 裂隙之谜 —— 悬崖 A

**体感**：从“城市时间案”跳到“平行世界/起源档案/虚空战争/存在主义”，60 章内层级过密。

| 区间 | 代表章 | 风险 | 诊断 |
|------|--------|------|------|
| 61–75 | 裂隙入口 / 平行世界 / 重新定位 | 中 | 第61章仍有情感锚点（“你有我”），可跟；但记忆冲突/身份危机开始抽象 |
| **76–82** | 时间档案馆 / 共同的祖先 / 第一次接触 / **时间的语言** | **高** | **本卷最大弃读带**。第80章起源档案、第82章“时间的语言”（均破折号 178–218）几乎是概念课 |
| 85–96 | 虚空来客 / 准备战斗 / 现实瓦解 / 幽灵归来 | 中 | 有战斗外壳，但威胁仍是宇宙级；第96章幽灵短暂回归是难得的“旧敌人” |
| 100–110 | 百章里程碑 / 重建 / **存在的意义** | **高** | 第100章像总结汇报；第110章“存在的意义”纯对话哲学（约 6864 字、具象极低） |
| 115–120 | 更大图景 / 远征 | 中 | 远征出发可作下一钩，但前提是读者还愿上船 |

**第二卷量化问题**：

- 均破折号 99.2；ch93 达 **277**，ch82 **218**——正是“现实瓦解”“时间的语言”这类概念章。
- 具象占比从 0.68 掉到 0.38。
- 角色断线开始显性化：幽灵/人类纯粹运动弱化，陈明远功能被架空，苏婉清铺垫依赖后期补丁。

**必须改**：

1. **合并/压缩 76–82、106–110** 的设定对话，把“起源/语言/存在”拆进带失败风险的行动（档案馆被虚空侵蚀、语言学习伴随身体/意识损伤、和平被具体恐怖事件打断）。
2. **第二卷必须有一条城市回线**：哪怕 3–5 章回新上海——议会弹劾、市民因裂隙失忆、底层暴动——让读者记得“这故事和人有关”。
3. 幽灵线：第89/96 有回归痕迹，但需要**持续对抗**，不是一次性插叙。

### 第三卷（121–180）· 暗影崛起 —— 悬崖 B 前半

**体感**：黎明号远征、虚空边界、维度/多重宇宙。第121章开篇已是“银河视野中航行七天”，读者与第一卷的情感距离被拉开。

| 区间 | 风险 | 诊断 |
|------|------|------|
| 121–140 | 中–高 | 远征开场可接受，但**没有回城市的具体赌注**；抽象词频全书最高区间之一 |
| 141–160 | 高 | 新文明/新存在/维度守护者密度过高；第160章“新存在”诞生缺乏过程（审查已点名） |
| **170–173** | **极高** | 第170《维度的真相》、第173《维度的融合》：正文几乎全是概念定义（“超越颜色/超越光”），ch170 具象词几乎为 0 |
| 174–180 | 高 | 若仍是“更大图景”，读者已完成“这本书会一直更大”的预期，失去追更动机 |

**第三卷数据**：抽象词均频 **76.3**（全书卷均最高），具象占比 **0.20**。这是商业读者第二卷末到第三卷集中流失的结构性原因。

**本卷标题模式预警**（大纲层面）：“维度/真相/传承/新存在”类标题密集，读者扫目录就会判断“设定书”。
