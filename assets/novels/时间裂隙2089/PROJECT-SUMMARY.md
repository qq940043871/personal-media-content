## 💡 使用示例

### 示例1：开始新小说
```
你：开始新小说

AI：好的！让我们创建你的科幻小说。请告诉我：

1. 小说叫什么名字？
2. 故事发生在什么时代？
3. 主要的科技水平如何？
4. 有哪些主要角色？
5. 核心冲突是什么？
```

### 示例2：写作章节
```
你：写第1章

AI：[读取所有设定文档]

# 第一章 地球之晨

[3000-5000字详细内容]

---
写作完成报告：
- 字数：4,523字
- 新增设定：穹顶城市
- 角色变化：主角登场
- 伏笔：神秘信号
```

### 示例3：一致性检查
```
你：检查一致性

AI：## 一致性检查报告

### 发现的问题
❌ 第2章说主角在地球，第3章突然在火星

### 建议的修复
添加星际旅行描写

### 通过的检查
✅ 科技设定一致
✅ 角色性格一致
```

## 🎨 定制选项

### 修改世界观
直接编辑 `novel/world-building.md` 文件。

### 添加角色
编辑 `novel/characters.md` 文件，或说"添加角色[名称]"。

### 调整情节
编辑 `novel/plot-outline.md` 文件。

### 查看设定
说"查看世界观"或"查看角色"。

## 🔧 高级功能

### 1. 角色发展追踪
```
查看角色李明的发展
```
系统会显示从第一章到当前章节的角色变化。

### 2. 情节回顾
```
回顾剧情
```
生成完整的故事摘要和未解决的伏笔。

### 3. 科技设定扩展
```
引入新科技：量子传输
```
系统会检查与现有科技的一致性。

### 4. 支线管理
```
查看支线剧情
```
显示所有支线的状态和与主线的关系。

## 📈 最佳实践

1. **先规划后写作** - 花时间完善世界观和角色
2. **定期检查一致性** - 每3-5章检查一次
3. **及时更新记录** - 写完章节立即更新笔记
4. **善用伏笔** - 提前规划，适时揭示
5. **保持角色一致** - 每个角色都要有独特性格
