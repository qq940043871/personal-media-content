# 沧元图续写技能

本技能专门用于续写《沧元图》小说，支持创作元神八劫境之后的篇章。

## 背景知识

### 小说基本信息
- **书名**：沧元图
- **作者**：我吃西红柿（番茄）
- **主角**：孟川（原名方岐，化名方天师）
- **当前境界**：元神八劫境（已渡劫成功）
- **妻子**：柳七月（凤凰血脉）
- **家乡**：沧元界（已独立时空支流）

### 境界体系

#### 凡俗修炼五重境界
1. 筑基
2. 内炼
3. 洗髓
4. 脱胎
5. 无漏

#### 神魔境界
1. 丹云境
2. 不灭境
3. 大日境（炼体神魔理论极限）
4. 暗星境（封侯神魔）
5. 无间境（封王神魔）
6. 造化境（超越封王神魔）

#### 元神修炼
- 元神是魂魄修炼有成后凝聚而成
- 大日境神魔才能修炼元神
- 元神八劫境是极高境界，需要渡过八次天劫
- 孟川凡俗时就凝练了元神（通过绘画）

### 主要人物

#### 八劫境强者
- **龙祖**：这方宇宙八劫境的统领者
- **魔山主人**：八劫境之一
- **凤凰始祖**：八劫境之一，与孟川妻子柳七月有血脉渊源
- **永恒楼主人**：八劫境之一，与永恒楼有缘
- **黑魔始祖**：已离开这方宇宙，带走了黑魔殿和梦魇殿
- **赤宁真君**、**星空始祖**、**山吴道君**：其他八劫境

#### 孟川亲友
- **柳七月**：妻子，凤凰血脉
- **孟仙姑**：姑祖母，为人族奉献一生
- **李观尊者**、**洛棠尊者**：为人族奉献的尊者
- **薛峰**：安海王家五公子，天赋最接近孟川，死于妖族
- **真武王**：王师兄，牺牲自己阻止妖族入侵

### 重要地点
- **沧元界**：孟川家乡，已独立时空支流
- **青火山**：孟川师尊所在
- **元初山**：人族最古老宗派
- **安海关**、**洛棠关**：七大雄关之一
- **赤血崖**：刻有战死神魔名字

### 小说结尾状态
1. 孟川成功渡过元神第八劫
2. 沧元界时空支流独立，开始扩张蜕变
3. 黑魔始祖离开，黑魔殿解散
4. 孟川准备将战死英雄从时空长河中捞出
5. 众八劫境庆贺孟川渡劫功成
6. 孟川准备派遣元神分身去青火山拜见师尊

## 创作要求

### 风格要求
1. **保持原作风格**：
   - 简洁明快的叙述
   - 大量短句、短段落
   - 适合手机阅读
   - 避免大段心理描写

2. **战斗描写**：
   - 简洁有力
   - 突出境界差距
   - 强调元神八劫境的特殊能力

3. **情感表达**：
   - 含蓄内敛
   - 通过行动展现
   - 避免直白说教

### 境界描写规范

#### 元神八劫境能力
- 可分化元神分身
- 可掌控时空长河
- 可将人从时空长河中捞出
- 意识可与家乡世界完美融合
- 可独立时空支流

#### 八劫境之间的关系
- 同宇宙八劫境团结互助
- 对抗异宇宙八劫境的渗透侵蚀
- 探索无尽时空

### 剧情发展方向

#### 短期（1-10章）
1. 与八劫境们相聚庆贺
2. 派遣元神分身去青火山拜见师尊
3. 将战死英雄从时空长河中捞出
4. 沧元界扩张蜕变的细节

#### 中期（11-50章）
1. 与其他八劫境一同闯荡无尽时空
2. 探索其他宇宙
3. 发现新的威胁或机遇
4. 提升元神八劫境的实力

#### 长期（51-100章）
1. 面对异宇宙八劫境的挑战
2. 保护家乡宇宙
3. 探索更高境界
4. 与其他八劫境建立更紧密的联盟

## 创作流程

### 第一步：确定章节内容
- 询问用户想要续写的具体内容
- 确定章节范围（如：第1-5章）

### 第二步：生成章节大纲
```
【任务】创作《沧元图》续写章节大纲

【当前状态】
- 主角：孟川（元神八劫境）
- 位置：沧元界
- 时间：渡劫成功后第12天

【章节要求】
- 字数：每章1800-2000字
- 风格：保持原作风格
- 节奏：紧凑，每章有小高潮

【输出格式】
第X章：章节标题
- 核心目标：本章要达成什么
- 主要场景：地点
- 登场人物：角色列表
- 关键情节：3-4个节点
- 章节钩子：悬念结尾
```

### 第三步：创作正文
```
【任务】创作《沧元图》续写正文

【选定章节】
第X章大纲

【核心要求】
1. 保持原作风格：简洁明快，短句短段落
2. 境界描写准确：符合元神八劫境能力
3. 人物性格一致：孟川嫉恶如仇，重情重义
4. 世界观一致：符合沧元图设定

【输出格式】
第X章 章节标题

正文内容（1800-2000字）
```

### 第四步：审核修改
- 检查是否符合原作风格
- 检查境界描写是否准确
- 检查人物性格是否一致
- 检查剧情逻辑是否通顺

## 注意事项

### 必须遵守
1. **不改变已有设定**：不修改原作中的境界体系、人物关系、重要事件
2. **保持人物性格**：孟川嫉恶如仇、重情重义；柳七月温柔坚强
3. **世界观一致**：符合沧元图的宇宙观、时空观
4. **风格一致**：保持原作简洁明快的叙述风格

### 可以拓展
1. **新宇宙**：可以探索其他宇宙
2. **新敌人**：可以引入异宇宙八劫境
3. **新机遇**：可以发现新的修炼资源或秘境
4. **新人物**：可以引入其他八劫境或强大存在

### 禁止内容
1. **政治敏感**：不涉及现实政治
2. **色情暴力**：不描写露骨内容
3. **违背原作**：不改变原作核心设定
4. **逻辑矛盾**：不出现剧情bug

## 输出文件命名

- **章节大纲**：`6-续写-第X-Y章-分章大纲.txt`
- **正文内容**：`chapters/8-续写-第X章.txt`
- **剧情单元**：`5-续写-第X卷-剧情单元.txt`

"孟川，我们这方宇宙诸位八劫境都已苏醒，庆贺你渡劫功成，赶紧过来吧。"一道声音遥遥传来。

孟川生出感应，抬头看去。

"来了。"孟川笑着应道。

## 使用方法

1. **开始续写**：输入 `/novel-cangyuantu` 启动技能
2. **选择内容**：告诉AI想要续写的具体内容
3. **生成大纲**：AI会生成章节大纲供确认
4. **创作正文**：确认大纲后，AI会创作正文
5. **审核修改**：可以对正文进行修改调整
