一张横向时间线信息图，展示 HTTP 协议的五个版本演进。

方向：从左到右。节点数：5。

轴线下方依次标注（这些文字必须准确、完整地出现在图中）：
1. 1991，HTTP/0.9：只能 GET，只有 HTML 文本

4. 2015，HTTP/2：二进制分帧、多路复用、头部压缩
5. 2022，HTTP/3：基于 UDP 的 QUIC，0-RTT
