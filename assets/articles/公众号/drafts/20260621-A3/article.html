SFT → RLHF → DPO：大模型对齐技术演进路线

从监督微调到人类反馈强化学习，再到直接偏好优化——大模型对齐（Alignment）的三次范式跃迁，正在重新定义AI能力的边界。

什么是对齐？为什么它如此重要？

当我们谈论大语言模型（LLM）的能力时，"对齐"是一个绕不开的核心概念。简单来说，对齐是指让模型的行为与人类的意图、偏好和价值观保持一致。一个未经对齐的模型，即使拥有海量知识，也可能输出有害、偏见或完全无关的内容。

预训练阶段赋予模型语言理解和知识储备的能力，但这种能力是"野蛮生长"的——模型学会了预测下一个token，却没有学会如何做一个有用的、安全的助手。对齐技术的目标，就是在保留模型能力的同时，将其行为"修剪"到人类期望的轨道上来。

从技术演进的角度看，大模型对齐经历了三个关键阶段：SFT（Supervised Fine-Tuning，监督微调）、RLHF（Reinforcement Learning from Human Feedback，基于人类反馈的强化学习）和DPO（Direct Preference Optimization，直接偏好优化）。这三者并非简单的替代关系，而是逐步深化的演进路线。

第一站：SFT——教会模型"说话"

基本原理

SFT是大模型对齐的第一步，也是最直观的一步。其核心思想非常简单：收集一批高质量的"指令-回答"对，然后用监督学习的方式对预训练模型进行微调。

具体来说，给定一个指令 x 和对应的理想回答 y，SFT的训练目标是最大化：

СSFT = 𝔼(x,y)~D [ ∑t=1|y| log Pθ(yt | x, y<t) ]

这本质上就是一个标准的序列到序列的交叉熵损失。模型学习在给定指令的条件下，逐步生成与标注数据尽可能一致的token序列。

SFT的优势与局限

SFT的优势在于实现简单、训练稳定。它直接告诉模型"什么是对的"，模型只需要模仿即可。在实践中，SFT能够显著提升模型的指令遵循能力，让原本只会"续写文本"的模型学会"回答问题"。

但SFT的局限也很明显。首先，它依赖大量高质量标注数据，而这类数据的获取成本极高。其次，SFT只能告诉模型"什么是好的"，却无法告诉它"什么是不好的"——模型缺乏对负面样本的学习。更重要的是，对于开放式生成任务，"正确答案"往往不止一个，SFT的逐token模仿策略难以捕捉这种多样性。

工程实践中的SFT

在实际应用中，SFT的数据质量远比数据量重要。InstructGPT的实验表明，仅用约13000条高质量标注数据进行SFT，就能让GPT-3在指令遵循能力上产生质的飞跃。数据构建通常遵循以下几个原则：

  • 多样性：覆盖不同任务类型（问答、摘要、翻译、代码生成等）
  • 准确性：回答需要事实正确、逻辑清晰
  • 安全性：包含对有害指令的拒绝回答样本
  • 格式一致性：统一的输出格式有助于模型学习结构化响应

第二站：RLHF——让人类偏好成为训练信号

从SFT到RLHF的动机

SFT虽然有效，但它本质上是一个"模仿学习"过程——模型只是在模仿标注者的写作风格和回答方式。然而，人类对"好回答"的评判标准是复杂的、主观的、难以用简单的标注来完全捕捉的。

比如，对于同一个问题，两个标注者可能写出完全不同但都合理的回答。SFT无法处理这种"多解性"。我们需要一种新的范式，让模型能够学习人类的偏好，而不仅仅是模仿人类的行为。

RLHF的三阶段流程

RLHF由OpenAI在InstructGPT（2022年）中系统化提出，其训练流程分为三个阶段：

阶段一：SFT预训练

首先使用高质量标注数据对预训练模型进行SFT微调，得到一个初始的对话模型。这一步为后续的强化学习提供了一个合理的起点。

阶段二：奖励模型训练

收集人类偏好数据。具体做法是：给定一个指令，让SFT模型生成多个回答，然后由人类标注者对这些回答进行排序（而非逐条打分）。使用Bradley-Terry模型，将排序转化为奖励：

P(yw ≻ yl | x) = σ(rφ(x, yw) - rφ(x, yl))

其中 rφ 是奖励模型，yw 和 yl 分别是被偏好的和不被偏好的回答。通过最大化偏好数据的似然，训练一个能够预测人类偏好的奖励模型。

阶段三：PPO强化学习

使用PPO（Proximal Policy Optimization）算法，以奖励模型的输出作为奖励信号，对SFT模型进行进一步优化：

maxθ 𝔼x~D, y~πθ [ rφ(x, y) - β · DKL(πθ ∥ πref) ]

其中 πθ 是当前策略，πref 是SFT参考模型，β 是KL散度惩罚系数。KL惩罚项的作用是防止模型在追求高奖励的过程中"跑偏"太远，保持与SFT模型的合理距离。

RLHF的工程挑战

RLHF虽然效果显著，但其工程复杂度也令人望而生畏：

  1. 训练不稳定：PPO本身是一个复杂的强化学习算法，涉及多个神经网络（策略模型、参考模型、奖励模型、价值模型）的协同训练，超参数敏感，调优困难
  2. 计算成本高：每个训练步骤需要多次前向和反向传播，显存占用约为SFT的4倍
  3. 奖励模型脆弱：奖励模型可能被"hack"——模型学会生成奖励模型喜欢的"套路化"回答，而非真正高质量的回答（即reward hacking问题）
  4. 人类标注成本：偏好数据的收集需要大量人工，且标注一致性难以保证

第三站：DPO——绕过强化学习的捷径

DPO的核心洞察

DPO（Direct Preference Optimization）由斯坦福大学在2023年提出，其核心洞察极为精妙：奖励模型和RL训练是可以合并的。

传统RLHF需要先训练奖励模型，再用RL优化策略。DPO证明了这两步可以解析地合并为一步——直接用偏好数据优化策略模型，完全不需要显式的奖励模型和RL训练。

具体来说，DPO推导出了最优策略与奖励函数之间的闭式解：

r*(x, y) = β log (π*(y|x) / πref(y|x)) + β log Z(x)

将这个关系代入Bradley-Terry偏好模型，得到DPO的损失函数：

СDPO = -𝔼(x, yw, yl) [ log σ( β log (πθ(yw|x) / πref(yw|x)) - β log (πθ(yl|x) / πref(yl|x)) ) ]

这个损失函数的直觉非常清晰：它鼓励模型提高被偏好回答的相对概率，同时降低不被偏好回答的相对概率，且这种调整是相对于参考模型而言的。

DPO的优势

与RLHF相比，DPO具有以下显著优势：

  1. 实现简单：只需要标准的监督学习训练循环，无需PPO、价值模型等复杂组件
  2. 训练稳定：不存在RL训练中的不稳定性问题
  3. 计算高效：显存占用与SFT相当，约为RLHF的1/4
  4. 超参数少：核心超参数只有一个温度系数 β

在多项基准测试中，DPO的表现与RLHF相当甚至更优，这使其迅速成为工业界的主流选择。

DPO的局限与改进方向

DPO并非完美无缺。其主要局限包括：

  • 对参考模型敏感：DPO的性能高度依赖SFT参考模型的质量，如果参考模型太弱，DPO的效果会大打折扣
  • 分布偏移问题：DPO使用离线数据训练，但评估时模型需要在线生成，这种分布偏移可能导致次优解
  • 隐式奖励的可解释性差：DPO不产生显式的奖励模型，这使得我们难以理解和调试模型的偏好学习过程

针对这些问题，后续工作提出了多种改进方案。IPO（Identity Preference Optimization）通过修改损失函数增强了对噪声标签的鲁棒性；KTO（Kahneman-Tversky Optimization）进一步简化了数据需求，只需要"好/坏"二元标签而非成对偏好数据；ORPO（Odds Ratio Preference Optimization）则将SFT和偏好优化合并为单一阶段。

从实际部署来看，当前工业界的主流做法是SFT + DPO的两阶段流程：先用SFT教会模型基本的指令遵循能力，再用DPO进一步对齐模型的偏好。RLHF虽然在某些场景下仍有优势（如需要在线探索的任务），但其高昂的工程成本使其逐渐退出了中小规模团队的选择范围。

对齐技术的前沿趋势

迭代式对齐

当前的对齐训练通常是一次性的，但研究表明，迭代式对齐（Iterative Alignment）能够持续提升模型质量。具体做法是：使用当前模型生成数据 → 人类标注偏好 → 训练新模型 → 循环。这种"自我进化"的范式正在成为新的研究热点。

过程对齐（Process Supervision）

传统的对齐方法只关注最终输出的质量（结果对齐），而过程对齐则关注推理过程中每一步的正确性。OpenAI的PRM（Process Reward Model）研究表明，过程对齐在数学推理等需要严谨逻辑的任务上具有显著优势。

宪法AI（Constitutional AI）

Anthropic提出的Constitutional AI尝试用一组明确的"宪法原则"来指导模型的自我对齐，减少对人类标注的依赖。模型根据这些原则自我批评和修正回答，形成一种"自监督"的对齐方式。

多目标对齐

现实世界中的偏好往往是多维度的（有用性、安全性、诚实性、格式规范等），单一的奖励信号难以平衡这些维度。多目标对齐技术尝试为每个维度独立建模，通过加权或约束优化的方式实现多维度的平衡。

写在最后

从SFT到RLHF再到DPO，大模型对齐技术的演进路线呈现出一个清晰的趋势：在保持对齐效果的前提下，不断降低工程复杂度和计算成本。

SFT奠定了对齐的基础，RLHF引入了人类偏好的学习范式，DPO则证明了"简单即美"的工程哲学。但这并非终点——随着模型能力的持续增长和应用场景的不断扩展，对齐技术还将继续演进。

对于工程团队而言，理解这三种方法的原理和权衡，是构建高质量大模型应用的基础。在实践中，没有放之四海而皆准的方案——选择哪种对齐方法，取决于你的数据条件、计算预算和应用需求。但有一点是确定的：对齐不是可选项，而是必选项。没有良好对齐的模型，就像没有方向盘的跑车——动力再强，也无法到达目的地。
