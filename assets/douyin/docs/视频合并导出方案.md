## 方案一：本地 ffmpeg 合并（推荐，技术方案）

### 步骤1：创建合并列表文件
在视频目录创建 `merge_list.txt`，内容如下：
```
file 'doubao_video_1.mp4'
file 'doubao_video_2.mp4'
file 'doubao_video_3.mp4'
file 'doubao_video_4.mp4'
file 'doubao_video_5.mp4'
```

### 步骤2：执行合并命令
```bash
cd "d:/ai_coder/hello_doubao_video"
ffmpeg -f concat -safe 0 -i merge_list.txt -c copy "末日废土机器人_完整版.mp4"
```
> `-c copy` 无损合并，速度极快，无画质损失。

### 步骤3（可选）：添加转场效果
如果视频间需要淡入淡出转场：
```bash
ffmpeg -i doubao_video_1.mp4 -i doubao_video_2.mp4 -i doubao_video_3.mp4 \
  -i doubao_video_4.mp4 -i doubao_video_5.mp4 \
  -filter_complex \
  "[0][1]xfade=transition=fade:duration=0.5:offset=9.5[v1]; \
   [v1][2]xfade=transition=fade:duration=0.5:offset=19[v2]; \
   [v2][3]xfade=transition=fade:duration=0.5:offset=28.5[v3]; \
   [v3][4]xfade=transition=fade:duration=0.5:offset=38[v4]" \
  -map "[v4]" -pix_fmt yuv420p "末日废土机器人_带转场.mp4"
```

## 方案二：GUI 工具 手动合并（零代码方案）

### 工具推荐

| 工具 | 平台 | 特点 | 链接 |
|------|------|------|------|
| **剪映** | Win/Mac/手机 | 免费，AI功能丰富，操作简单 | 剪映官网下载 |
| **Shotcut** | Win/Mac/Linux | 开源免费，无广告 | shotcut.org |
| **CapCut** | 在线/App | 国际版剪映，在线使用 | capcut.com |
| **Shotstack** | 在线 | 在线视频编辑器，无需安装 | shotstack.io |

### 剪映操作步骤（最简单）
1. 打开剪映 → 点击「开始创作」
2. 导入 5 个视频文件（按 doubao_video_1~5 顺序）
3. 拖入时间线，按顺序排列
4. 可选：在片段间添加「叠化」转场（0.3-0.5秒）
5. 点击右上角「导出」→ 选择 1080p / 4K → 导出

### CapCut 在线版操作步骤（无需安装）
1. 访问 capcut.com → 注册/登录
2. 新建项目 → 上传 5 个视频
3. 拖入时间线按顺序排列
4. 添加转场、调整时长
5. 导出下载到本地

## 四、一键自动合并脚本

将此脚本保存为 `merge_videos.bat`，双击运行即可自动合并：

```bat
@echo off
chdir /d "d:\ai_coder\hello_doubao_video"
echo 正在创建合并列表...
(
echo file 'doubao_video_1.mp4'
echo file 'doubao_video_2.mp4'
echo file 'doubao_video_3.mp4'
echo file 'doubao_video_4.mp4'
echo file 'doubao_video_5.mp4'
) > merge_list.txt
echo 正在无损合并视频...
ffmpeg -f concat -safe 0 -i merge_list.txt -c copy "末日废土机器人_完整版.mp4"
echo 合并完成！输出文件：末日废土机器人_完整版.mp4
del merge_list.txt
pause
```

> 前提：系统已安装 ffmpeg 并加入 PATH 环境变量。
