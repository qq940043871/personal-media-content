# 🚀 快速开始指南

## 安装完成！

未来世界小说写作系统已成功安装。以下是使用方法。

---

## 第一步：开始新小说

在对话中输入以下任一指令：

```
开始新小说
```

或

```
初始化小说
```

系统会引导你完成以下设置：

### 1️⃣ 基本信息
- 小说名称
- 时代背景
- 主要舞台

### 2️⃣ 世界观设定
- 科技水平
- 社会结构
- 地理环境
- 重要组织

### 3️⃣ 角色创建
- 主要角色（2-5个）
- 次要角色
- 角色关系

### 4️⃣ 情节规划
- 核心冲突
- 故事结构
- 支线剧情
- 预计章节

---

## 第二步：开始写作

### 写作新章节

```
写第1章
```

系统会：
1. ✅ 读取所有设定文档
2. ✅ 检查故事进度
3. ✅ 写作详细章节（3000-5000字）
4. ✅ 自动更新记录

### 继续写作

```
继续写
```

从上次中断的地方继续。

---

## 💡 使用技巧

### 1. 先规划后写作
花时间完善世界观和角色设定，故事会更连贯。

### 2. 定期检查一致性
每写3-5章检查一次，及时发现问题。

### 3. 及时更新记录
写完章节立即更新笔记，保持记忆完整。

### 4. 善用伏笔
提前规划伏笔，适时揭示，增加故事深度。

### 5. 保持角色一致
每个角色都要有独特的性格和说话方式。
