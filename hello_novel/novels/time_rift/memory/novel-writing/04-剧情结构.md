# 剧情结构规范

---

## 分卷结构模板

```markdown
| 卷 | 名称 | 章节范围 | 主题 | 核心矛盾 |
|----|------|----------|------|----------|
| 第一卷 | 卷名 | 第1-X章 | 主题 | 矛盾 |
| 第二卷 | 卷名 | 第X-X章 | 主题 | 矛盾 |
```

---

## 规模升级规则

舞台规模升级必须遵循"渐进原则"：

```
个人 → 城市 → 国家 → 星球 → 星系 → 宇宙 → 多重宇宙
```

每一步升级需要：
- 至少一卷的过渡期
- 新规模下的具体冲突（不能只是"更大的威胁"）
- 与前一规模的情感连接（不能让前文经历变得无关紧要）

## 叙事节奏曲线

```
张力
 │    ╱╲      ╱╲      ╱╲
 │   ╱  ╲    ╱  ╲    ╱  ╲
 │  ╱    ╲  ╱    ╲  ╱    ╲
 │ ╱      ╲╱      ╲╱      ╲
 └────────────────────────────→ 章节
```

节奏规则：
- 每10-15章一个小高潮
- 每30-50章一个大高潮
- 高潮之间必须有"喘息期"
- 连续高潮不超过3章

## 章节命名规范

### 命名原则
- 每章必须有标题，不能只有编号
- 标题反映本章核心事件或主题
- 标题风格全卷统一
- 标题字数控制在8字以内（中文）

### 命名风格

| 风格 | 适用场景 | 示例 |
|------|----------|------|
| 事件型 | 动作/高潮章节 | "第一次袭击"、"量子风暴" |
| 象征型 | 情感/哲学章节 | "时间的囚徒"、"机械之心" |
| 地点型 | 场景转换章节 | "深渊的入口"、"第八实验室" |
| 人物型 | 角色聚焦章节 | "李明的决定"、"ARIA的困惑" |
| 悬念型 | 过渡/铺垫章节 | "数据的碎片"、"裂隙的召唤" |

### 命名规则
- 同一卷内命名风格保持一致
- 同一卷内不要出现超过2个以上相同风格的标题
- 关键章节（卷首/卷尾）使用象征型或事件型
- 避免与已有章节撞名

## 开篇章节规范

### 第一卷开篇（全书开头）
- 前3章必须建立：主角是谁、世界什么样、核心悬念
- 第1章必须有"钩子"——让读者想知道"接下来呢？"
- 不要在开篇大量解释设定——通过剧情自然展现

### 每卷开篇
- 前2章必须交代：时间跳跃（如果有）、主角当前状态、本卷核心矛盾
- 如果卷间有时间跳跃，必须在第1章明确说明
- 回顾前卷关键信息（不超过300字，融入对话或内心独白）

---

## 结尾章节规范

### 每卷结尾（终章）
- 必须收束本卷核心矛盾
- 必须留下下一卷的悬念或伏笔
- 必须有情感回应（角色对变化的感受）
- 结尾段落需要克制——不要过度解释

### 全书结尾
- 必须收束所有核心矛盾
- 必须回应开篇的主题
- 必须有情感高潮或温暖收束
- 最后一段要有"余韵"——让读者在合上书后仍然回味

### 结尾常见问题
| 问题 | 表现 | 修复方式 |
|------|------|----------|
| 结尾拖沓 | 矛盾解决后还有大量篇幅 | 在矛盾解决后3章内结束 |
| 解释过多 | 结尾成为设定说明 | 用角色行动和对话代替 |
| 情感不足 | 解决矛盾后无情感回应 | 加入角色的个人反应 |
| 悬念过少 | 没有为下一卷留钩子 | 增加1-2个新线索 |

## 章节字数标准

### 按章节类型

| 类型 | 字数范围 | 占比 | 说明 |
|------|----------|------|------|
| 开篇章节 | 4000-6000字 | 5% | 需要充分建立场景和悬念 |
| 日常推进 | 3000-5000字 | 50% | 标准叙事节奏 |
| 高潮章节 | 6000-10000字 | 15% | 战斗、揭示、转折 |
| 情感章节 | 4000-6000字 | 10% | 角色互动、内心戏 |
| 过渡章节 | 2000-3500字 | 10% | 场景切换、时间跳跃 |
| 终章 | 5000-8000字 | 5% | 收束、告别、新开始 |
| 番外/间章 | 1500-3000字 | 5% | 补充视角、背景故事 |

### 按叙事内容

| 内容类型 | 字数建议 | 说明 |
|----------|----------|------|
| 纯对话 | 2500-4000字 | 对话节奏快，字数可少 |
| 动作场面 | 4000-7000字 | 需要详细描写动作过程 |
| 环境描写 | 3000-5000字 | 建立氛围需要篇幅 |
| 内心独白 | 3000-5000字 | 深入角色心理需要空间 |
| 信息揭示 | 4000-6000字 | 重要信息需要铺垫和展开 |
| 哲学探讨 | 3000-5000字 | 思辨需要足够论证空间 |

### 按故事阶段

| 阶段 | 章节范围 | 单章字数 | 说明 |
|------|----------|----------|------|
| 开篇（前10%） | 第1-X章 | 4000-5500字 | 建立世界观和角色 |
| 发展（10%-40%） | 第X-X章 | 3500-5000字 | 推进剧情和关系 |
| 中段（40%-70%） | 第X-X章 | 4000-6000字 | 冲突升级和转折 |
| 高潮（70%-90%） | 第X-X章 | 5000-8000字 | 最激烈的冲突 |
| 收尾（后10%） | 第X-X章 | 4000-6000字 | 解决和告别 |

### 字数控制要点

- **上限**：单章不超过10000字（超过则拆分为上下两章）
- **下限**：单章不低于2000字（低于则合并到相邻章节）
- **波动范围**：相邻章节字数差异不超过50%（避免忽长忽短）
- **每卷总量**：一卷60章约25-35万字（单章平均4000-6000字）

### 字数不足时的扩充技巧

| 技巧 | 说明 | 适用场景 |
|------|------|----------|
| 增加环境描写 | 补充场景细节 | 场景转换时 |
| 深化内心戏 | 展示角色思考过程 | 重要决策时 |
| 扩展对话 | 增加对话轮次和细节 | 信息交流时 |
| 加入回忆 | 插入相关回忆片段 | 需要背景时 |
| 增加支线 | 引入次要角色或事件 | 需要丰富时 |

### 字数过多时的精简技巧

| 技巧 | 说明 | 适用场景 |
|------|------|----------|
| 合并场景 | 将多个小场景合并 | 场景碎片化时 |
| 删减重复 | 删除重复的描写和对话 | 冗余时 |
| 压缩过渡 | 简化场景切换的过渡 | 过渡冗长时 |
| 精简环境 | 保留关键细节，删除次要 | 环境过多时 |
| 拆分章节 | 将内容拆为上下两章 | 内容过多时 |

## 描写规范

| 类型 | 占比限制 | 说明 |
|------|----------|------|
| 环境描写 | ≤15% | 每章至少一段 |
| 内心独白 | ≤20% | 重要决策时刻使用 |
| 动作场面 | 具体化 | 不能过于抽象 |
| 哲学对话 | ≤30% | 融入行动场景 |

---

## 主题表达规范

| 层次 | 说明 | 表达方式 |
|------|------|----------|
| 表层主题 | 故事在讲什么 | 剧情本身 |
| 中层主题 | 故事在探讨什么 | 角色选择和冲突 |
| 深层主题 | 故事在回答什么 | 哲学对话和领悟 |

表达原则：
- **不要说教**：让角色用行动体现主题
- **留白**：最深刻的主题往往是"没有说出口的部分"
- **首尾呼应**：开头和结尾的主题表达形成对称

## 情感锚点类型

| 类型 | 频率 | 示例 |
|------|------|------|
| 日常温暖 | 每5-10章 | 一起喝咖啡、看日落 |
| 情感爆发 | 每30-50章 | 哭泣、告白、争吵 |
| 克制悲伤 | 每50-100章 | 墓前独白、回忆旧友 |
| 哲学领悟 | 每80-120章 | 对存在意义的理解 |
