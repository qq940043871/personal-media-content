# 未来世界小说写作系统

这是一个专为科幻/未来世界长篇小说设计的AI辅助写作系统，具有完整的记忆管理功能，确保故事连贯、不矛盾。

## ✨ 特性

- 📚 **完整的世界观管理** - 科技、社会、地理、组织设定
- 👥 **角色档案追踪** - 详细的角色信息和发展轨迹
- ⏰ **时间线记录** - 精确的事件时间管理
- 📖 **情节大纲规划** - 结构化的故事规划
- 📝 **写作笔记系统** - 每章关键点记录
- ✅ **一致性检查** - 自动检测前后矛盾
- 🔍 **伏笔管理** - 追踪伏笔的埋设和揭示

## 📁 文件结构

```
novel/
├── world-building.md      # 世界观设定
├── characters.md          # 角色档案
├── timeline.md            # 时间线/事件年表
├── plot-outline.md        # 情节大纲
├── writing-notes.md       # 写作笔记/关键点摘要
└── chapters/              # 章节文件夹
    ├── chapter-01.md
    ├── chapter-02.md
    └── ...
```

## 🚀 快速开始

### 1. 初始化新小说

直接说：
```
开始新小说
```
或
```
初始化小说
```

系统会引导你创建：
- 世界观背景
- 主要角色
- 情节大纲
- 时间线

### 2. 写作章节

说：
```
写第1章
```
或
```
继续写
```

系统会：
1. ✅ 自动读取所有设定文档
2. ✅ 检查故事进度
3. ✅ 写作3000-5000字的详细章节
4. ✅ 自动更新所有记录

### 3. 检查一致性

说：
```
检查一致性
```

系统会：
- 扫描所有章节
- 检测时间、地点、角色、科技设定的矛盾
- 输出详细的问题报告

### 4. 回顾剧情

说：
```
回顾剧情
```
或
```
查看角色发展
```

系统会生成：
- 完整的故事摘要
- 角色发展轨迹
- 未解决的伏笔列表

## 📋 可用指令

| 指令 | 功能 |
|------|------|
| `开始新小说` / `初始化小说` | 创建新的小说项目 |
| `写第X章` | 写作指定章节 |
| `继续写` | 从上次中断的地方继续 |
| `检查一致性` | 检查故事的一致性 |
| `回顾剧情` | 生成剧情回顾 |
| `查看角色` | 显示角色发展 |
| `更新设定` | 修改世界观/角色设定 |

```
用户：开始新小说

2. 故事发生在什么时代？

```

```
用户：写第3章

AI：[先读取所有设定文档]

火星殖民地的警报声划破了黎明的宁静...
```

```
### 通过的检查
```

## 🎯 核心优势

### 1. 永不失忆
- 每次写作前自动读取所有设定
- 完整的关键点记录
- 详细的时间线追踪

### 2. 避免矛盾
- 自动一致性检查
- 角色状态追踪
- 设定变更记录

### 3. 深度写作
- 每章3000-5000字
- 细腻的场景描写
- 丰富的对话内容

### 4. 结构化管理
- 清晰的文件组织
- 标准化的记录格式
- 易于检索和回顾

## 📖 写作建议

1. **先规划后写作** - 花时间完善世界观和角色设定
2. **定期检查一致性** - 每写3-5章检查一次
3. **及时更新记录** - 写完章节立即更新笔记
4. **善用伏笔** - 提前规划，适时揭示
5. **保持角色一致** - 每个角色都要有独特的性格

## 🔧 高级功能

### 自定义设定
你可以随时修改 `novel/` 文件夹中的任何文档来更新设定。

### 导出作品
所有章节都在 `novel/chapters/` 文件夹中，可以直接复制使用。

### 备份项目
整个 `novel/` 文件夹就是你的小说项目，可以随时备份。

## ❓ 常见问题

**Q: 如果我中断了写作怎么办？**
A: 直接说"继续写"，系统会自动从上次中断的地方继续。

**Q: 如何修改已写的章节？**
A: 说"修改第X章"，系统会读取并允许你编辑。

**Q: 可以同时写多条支线吗？**
A: 可以！系统会自动管理支线和主线的关系。

**Q: 如何添加新角色？**
A: 说"添加角色[名称]"，系统会引导你创建完整档案。
