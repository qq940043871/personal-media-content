## 修复策略（三层）

### 层1 · 精确替换（高置信）

- **ch527 临终敲击语**：`别，哭。好，好，\1。` → `别，哭。好，好，的。`；`照，顾，自，\1。` → `照，顾，自，己。`
- **ch184 损坏的叙述标签**（`\1静` / `\1暖` / `\1说在于`）：还原为标准 ARIA/角色声音标签，例如 `"我是说，\1静，"我们需要` → `"我是说，"ARIA的声音中带着一种深沉的、像是大海一样的平静，"我们需要`
- **已知残缺从句**：按上下文补全 5–20 字短句，不改剧情

### 层2 · 结构规则（叙述体）

| 模式 | 处理 |
|------|------|
| `，\1。`（前句完整） | → `。` |
| `，\1，` | → `，` |
| `不是A，\1。而是B。` | → `不是A，而是B。` |
| `而是\1+内容` | → `而是+内容` |
| `是\1+内容` | → `是+内容` |
| 对白未完 `"...，\1` + 换行 | → `"...……"`（省略号收口） |
| ch527 摩斯电码式断词 | 精确补全末字 |

### 层3 · 质量回扫

- 消除 `，……"` / `……。"` 等批量删除引入的标点别扭
- 对 bulk 删除后不完整的短句二次补全（pass2 共 62 处）
- **不改动**原文既有的文学性 `，……` 停顿（如 ch121/123/124/126 的「倾听它们，……爱它们」体）
